# R training

## Tidyverse package collection

The last presentation of the 3rd and the 4th of March 2025 is available through the following [link](https://umr-marbec.github.io/tidyverse-training/). You can also download a pdf version of the presentation by launching the R code below: 

``` r
install.packages("pagedown")
pagedown::chrome_print(input = "https://umr-marbec.github.io/tidyverse-training/#/section.html")
```
In addition you can find all the archived version on [zenodo](https://doi.org/10.5281/zenodo.14870199) website.
